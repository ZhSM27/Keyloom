# Security

The HTTP workbench binds only to loopback and is intended for one trusted local user. It has no authentication and must not be exposed to the internet or shared through a public tunnel. Uploaded audio and exports remain on the host.

Use the matching release model bundle. The installer accepts only catalogued file names and verifies sizes and SHA-256 values before installation. Checkpoints load with PyTorch's `weights_only=True`; integrity checks are not a substitute for trusting the release publisher.

Report vulnerabilities using GitHub's private vulnerability reporting when the repository owner enables it. Do not attach credentials or private audio to public issues.
